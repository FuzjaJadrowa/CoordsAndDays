A combined Minecraft datapack and resourcepack that displays your current coordinates and day count on the left-top corner.

**WARNING! Resourcepack is required for correct datapack working!**
## Features
* Shows synced player position coordinates.
* Shows actual world day count.
* Thanks for the VSH shaders and negative spaces in the resourcepack, the datapack perfectly alignes actionbar to the left-top corner.

## Datapack Installation
1. Download `CoordsAndDays-pack.zip`.
2. Copy this ZIP into `.minecraft/resourcepacks` and activate it in options.
3. Copy the same ZIP into the selected world's `datapacks` folder.
4. Join the world. The datapack is now installed and ready to use.

## Mod Installation
1. Download `CoordsAndDays-fabric.jar`.
2. Drop it into `.minecraft/mods`.
3. Reload the game and join the world. The datapack is now installed and ready to use.
